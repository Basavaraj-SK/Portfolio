# Basavaraj S. K. — Creative Developer Portfolio

An interactive, high-performance personal developer portfolio and systems engineering showcase for **Basavaraj S. K.** (Full-Stack Developer & MCA Graduate based in Bangalore, India).

Built with **React 18**, **Vite**, **Tailwind CSS**, **Framer Motion**, and **HTML5 Canvas API**.

---

## ⚡ Key Highlights & Engineering Features

- **3D Parallax Tilt & Specular Reflection**: Interactive glassmorphic Hero card with dynamic `rotateX`, `rotateY`, specular gloss tracking cursor coordinates, and custom Dot Matrix portrait art.
- **Matrix Text Cypher Scrambler**: Automatically deciphering headline cycler cycling through core engineering competencies.
- **HTML5 Canvas Particle Mesh**: 60 FPS floating constellation background reacting elastically to cursor proximity.
- **Dynamic Spotlight & Physics Follower Cursor**: Smooth trailing outer ring with spring damping and radial lighting beam.
- **Categorized Bento Tech Grid**: Authentic SVG brand badges from `simple-icons` with localized brand glows and 3D card tilt.
- **3D Holographic Projects Showcase**: Deep-dive case studies for *AttendFlow*, *Cloud Kitchen Suite*, and *RAG Assistant* with architecture drawer inspection.
- **macOS zsh Interactive Terminal Sandbox**: Collapsible bottom dock CLI supporting commands: `help`, `tools`, `skills`, `theme <tokyo-night | matrix | obsidian>`, `sudo hire` (with confetti), and `clear`.
- **Direct Email Dispatch**: Serverless direct POST integration with reactive form validation, delivering directly to `basavarajsk2004@gmail.com`.
- **Web Audio API Micro-FX**: Zero-file procedural sound synthesizer for micro-clicks, alphanumeric keypress ticks, and celebratory chimes.

---

## 🛠 Tech Stack

- **Framework**: React 18 (TypeScript)
- **Bundler**: Vite
- **Styling**: Tailwind CSS, Custom Theme Variables (`[data-theme='tokyo-night' | 'matrix' | 'obsidian']`)
- **Animation**: Framer Motion
- **Icons**: Lucide React & Simple Icons
- **Effects**: HTML5 Canvas API, Web Audio API, Canvas Confetti

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Basavaraj-SK/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Typecheck and compile production bundle
npm run build

# Preview build locally
npm run preview
```
